## 📜 Грамматика языка `switch-lang`

Грамматика задана в форме Бэкуса-Наура (BNF):

<Программа> ::= <Оператор>
<Оператор> ::= SWITCH (I) {<СписокКейсов> <ПоУмолчанию>}
<СписокКейсов> ::= <СписокКейсов> <Кейс>
<СписокКейсов> ::= <Кейс> 
<Кейс> ::= CASE I : <СписокДействий> BREAK ;
<ПоУмолчанию> ::= DEFAULT : <СписокДействий>
<СписокДействий> ::= <СписокДействий> <Действие>
<СписокДействий> ::= <Действие>
<Действие> ::= print ( “Текст” ) ;


> 🔹 **Ключевые особенности**:
> - Единственная условная конструкция — `SWITCH (I)`, где `I` — **псевдослучайное целое от 0 до 7**, генерируемое при запуске.
> - В каждом `CASE` **только `I`** (не число!), то есть проверяется: совпадает ли значение `I` с текущим `case`?  
>   *(Примечание: такая конструкция семантически эквивалентна `if (true)`, но сохраняет структуру `switch`. Если задумано иначе — уточните.)*
> - Обязательное завершение `CASE` конструкцией `BREAK ;`.
> - `DEFAULT` **необязателен**, но если есть — должен быть в конце.
> - Единственное действие — `print("Текст");` (строка в двойных кавычках, точка с запятой в конце).

### Пример корректной программы

```text
SWITCH (I) {
  CASE I : print("Вариант 0"); BREAK ;
  CASE I : print("Вариант 1"); BREAK ;
  DEFAULT : print("По умолчанию");
}

1. Сборка:
make

2. Запуск с файлом:
./switch_translator examples/example1.txt

3. Запуск с опциями:
./switch_translator -a -v 2 examples/example1.txt

4. Интерактивный режим:
./switch_translator -i
